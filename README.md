# TV Дом

Главный экран для Google TV и Android TV в стиле Google TV, без рекламы. Здесь лежат готовые версии (APK) и скрипт
проверки телевизора на лишние приложения.

**Скачать:** [последняя версия](https://github.com/NerealNeSkill/tvdom-releases/releases/latest) → `TvDom.apk`.

## Установка

1. На телевизоре: Настройки → Система → Об устройстве → 7 раз нажмите «Сборка ОС Android TV». Затем Настройки →
   Система → Для разработчиков → включите «Отладка по USB». Запишите IP-адрес ТВ (Настройки → Сеть и Интернет).
2. На компьютере в той же сети установите [adb](https://developer.android.com/tools/releases/platform-tools) и выполните:
   ```bash
   adb connect 192.168.1.50:5555
   adb install -r TvDom.apk
   adb disconnect
   ```
   Если Google Play Защита пишет «Небезопасное приложение заблокировано», выберите «Подробнее» → «Всё равно установить».
3. На телевизоре откройте **TV Дом** → «Главный экран» → **TV Дом** и разрешите отладку, когда ТВ спросит
   (отметьте «Всегда разрешать»).

Вернуть стандартный экран: TV Дом → «Главный экран» → «Оригинал». Ничего не удаляется.

## Лицензия

7 дней бесплатно, дальше пожизненная лицензия за **150 ₽** со всеми обновлениями. Без лицензии главный экран
продолжает работать, только без рекомендаций.

Откройте TV Дом → «Лицензия и обновления», отправьте продавцу код телевизора (вида `ABCDE-23456`) вместе с оплатой.
Лицензия включится сама в течение нескольких минут, или нажмите «Проверить оплату».

## Обновления

TV Дом сам проверяет новые версии здесь, на GitHub, и предлагает обновиться (карточка на главном экране или
«Лицензия и обновления» → «Обновить»). Google Play не нужен.

## Проверка телевизора на лишние приложения

[debloat.py](debloat.py) показывает, что на ТВ можно безопасно отключить: рекламу, демо-режимы магазина, телеметрию,
сервисы, которые не работают в России. Для каждого пункта есть описание. Приложения не удаляются, а только
отключаются, и всё возвращается одной командой. Нужны Python 3 и adb.

```bash
python3 debloat.py 192.168.1.50            # проверить и выбрать, что отключить
python3 debloat.py 192.168.1.50 --report   # только посмотреть
python3 debloat.py 192.168.1.50 --restore  # вернуть всё обратно
```

Скрипт никогда не трогает изображение, звук, входы HDMI, пульт, обновления, Google Play и сервисы Google, а также
приложения, которые сохранили сеть Wi-Fi или нужны входам телевизора.

API TMDB, но TMDB не одобряет и не сертифицирует этот продукт.
